## 📥 Installation Guide — Firefox Only

### Step 1 — Install, Activate, and Pin Always Active Window 🔵

1. Open the official Firefox Add-ons page: **[Always Active Window (Always Visible)](https://addons.mozilla.org/en-US/firefox/addon/always-visible/)**.
2. Click **Add to Firefox** and confirm the installation.
3. Open Firefox's **Extensions** menu (puzzle-piece icon).
4. Find **Always active Window (Always Visible)** and pin it to the toolbar using its menu.
5. Open your Hitbullseye test page.
6. Click the **Always Active Window** icon in the toolbar once.
7. Confirm that the icon turns **blue**. This indicates that the extension is active for the current page.
8. If the icon does not turn blue, check the extension's settings and try again.

**Important:** Install and pin this extension before continuing. Its purpose is to make the page appear active even when you switch tabs. <https://addons.mozilla.org/en-US/firefox/addon/always-visible/>

### Step 2 — Download Hitbullseye Automate Tool

1. Open the [GitHub repository](https://github.com/ganesh-tadigadapa/Hitbullseye-extension-firefox).
2. Click **Code → Download ZIP**.
3. Extract the ZIP file to a folder on your computer.

Alternatively, clone the repository:

```bash
git clone https://github.com/ganesh-tadigadapa/Hitbullseye-extension-firefox.git
```

### Step 3 — Install Hitbullseye Automate Tool

1. Open Firefox and navigate to:

   `about:debugging#/runtime/this-firefox`

2. Click **Load Temporary Add-on...**.
3. Open the extracted project folder.
4. Select `manifest.json`.
5. Confirm that the extension appears in the list.

**Note:** Temporary add-ons may need to be loaded again after restarting Firefox.

### Step 4 — Pin Hitbullseye Automate Tool 📌

1. Click Firefox's **Extensions** menu.
2. Find **Hitbullseye Automate Tool**.
3. Open its options menu.
4. Select **Pin to Toolbar**.
5. Confirm that its icon is visible.

### Step 5 — Configure and Test Your API Key 🧪

1. Visit [Google AI Studio — API Keys](https://aistudio.google.com/apikey).
2. Create and copy an API key.
3. Click the pinned Hitbullseye Automate Tool icon.
4. Paste the key into the **API KEY** field.
5. Click **Test key**.
6. Wait for the success message.

If the test fails, check your key, account permissions, and API quota.

### Step 6 — Start Using the Extension 🚀

1. Open a Hitbullseye practice test where AI assistance is permitted.
2. Make sure Always Active Window is enabled (blue icon).
3. Click the pinned Hitbullseye Automate Tool icon.
4. Leave **ANSWER KEY** empty for AI solving.
5. Set the delay between questions.
6. Click **Start**.
7. Review the answers before submitting.

**Enjoy, guys! 🎉**
